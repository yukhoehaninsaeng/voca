# 1차 개발 요청 구현 상태

`development-request.md`의 수용 기준을 현재 코드와 자동 테스트에 대조한 결과다.

## 완료

- 입력 화면을 내 단어·내 문장 관리로 한정하고 단일 추가, 수정, 삭제, 검색, 다중 행 미리보기·등록을 제공한다.
- 내 콘텐츠, TOEIC Part 2~5, 핵심/마스터 어휘 팩, 오답 가상 Source를 학습선택에서 복수 선택할 수 있다.
- canonical key 기반 안정 ID, Source membership union 중복 제거, 해시 충돌 감지를 적용한다.
- 모든 신규 채점 경로는 `recordStudyEvent()`를 통해 `itemId` Progress와 StudyEvent를 함께 기록한다.
- 선택 Source의 전체·신규·오늘 복습과 오늘 풀이·정확도를 공통 selector로 계산한다.
- 선택 Source/Mode를 `vm-selection-v2`에 저장하고 새로고침 후 복원한다.
- 기존 `vm-*` 백업, 사용자 항목/오답 마이그레이션, `__w__` 충돌 보고, JSON 내보내기/검증/병합 복원을 지원한다.
- 사용자 입력과 AI 텍스트는 text node 또는 HTML escaping을 거쳐 출력한다.
- Whisper는 준비 중으로 비활성화하고 브라우저 Web Speech API 오류는 학습 오답으로 기록하지 않는다.

## 수동 확인 절차

1. 입력 화면에서 `apple | 사과`와 문장 여러 줄을 붙여넣고 미리보기의 유효/무효 행을 확인한 뒤 등록한다.
2. 학습선택에서 내 단어와 정적 어휘 팩을 함께 선택해 합집합 수와 플래시/객관식/입력 큐 수가 맞는지 확인한다.
3. 단어 Source만 선택해 빈칸·전체 받아쓰기·말하기가 사유와 함께 비활성화되는지 확인한다.
4. TOEIC P3 문장을 틀린 후 P4만 선택해 해당 오답이 인덱스가 같은 P4 문장에 표시되지 않는지 확인한다.
5. JSON을 내보낸 후 브라우저 저장소를 초기화하고 가져와 사용자 항목, Progress, 이벤트 및 선택이 복원되는지 확인한다.
6. `<img onerror=alert(1)>`을 단어로 등록해 텍스트로만 표시되고 실행되지 않는지 확인한다.
