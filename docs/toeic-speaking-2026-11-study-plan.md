# TOEIC Speaking 2026-11 단기 학습 계획 (IM1 90 → IM2 우선, IH 도전)

기간: 2026-10-27 ~ 2026-11-08 (KST). 시험 예정: 11월 첫째 주말(11/7 또는 11/8), 실제 응시일 확인 필요.

## 진단
- 질문에 맞는 일상 주제 답변은 작성 가능.
- 강점: I go to the gym four times a week; I like cooking chicken.
- 우선 보완: want to watching→want to watch, we are eat→we eat, it is make→it's easy to make, it have→it has, 관사/복수형, and 연속 사용.
- 텍스트만으로 발음·유창성·실전 등급 판정 불가.

## 일일 운영
- 09:00 신규 단어·표현 10개(뜻, 품사, 예문, 발음) + 패턴 2개; ChatGPT 예약 발송.
- 낮 15~25분: 신규 10개 뜻→영어 회상, 각 단어 예문 1문장, 소리 내어 읽기.
- 21:00 능동 회상 5개, 문장 만들기 3개, 30초 답변 1개; ChatGPT 예약 발송.
- 하루 총 권장 45~70분: 단어 15분, 문법·문장 20분, 스피킹 녹음 15~20분, 복습 10분.
- 새 단어는 배운 날(즉시/저녁), D+1, D+3, D+7에 복습. 오답은 당일 재시험 후 다음 날 다시 복습.
- 앱의 SRS Progress에는 recognition, recall, production을 구분하고, 객관식 정답만으로 '습득' 판정하지 않는다.
