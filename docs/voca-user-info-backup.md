# Voca 사용자 정보 파일과 브라우저 API 키

## 사용 방법

1. **마이 → AI 연결 · 내 학습 데이터**에서 OpenAI 또는 Anthropic을 선택하고 API 키를 저장한다.
2. 프리토킹, 대화 종료 피드백, 단어 AI 연상법은 `/api/user-ai` 경유로 선택한 제공업체를 사용한다. Vercel에 별도 API 키를 설정할 필요는 없다. 서버는 요청 중 키를 전달할 뿐 파일이나 DB에 보관하지 않는다. 다만 전송 중 서버가 키를 처리하므로 신뢰하는 배포 환경에서만 사용한다.
3. **백업 암호**를 10자 이상 입력한 뒤 `voca_user_info.json 저장`을 누른다.
4. 다른 기기에서 동일한 웹앱을 열고, 동일한 암호를 입력한 다음 백업 파일을 불러온다. 복원 후 앱이 새로고침된다.

## 백업 파일

- 암호화: PBKDF2-SHA256 (210,000회) + AES-256-GCM; 랜덤 salt/IV.
- 내용: `vm-*` 브라우저 localStorage 키의 스냅샷. 기존 단어, 문장, 학습 기록, SRS, 오늘 학습 계획, 프로필, 회화 복습, AI 설정 및 브라우저에 저장된 API 키가 포함될 수 있다.
- 기존 `vm-backup-v1-*` 자동 마이그레이션 백업은 중복 크기를 피하기 위해 제외.
- 이 파일은 **암호를 잊으면 복원할 수 없다.** 백업 파일을 공개 GitHub 저장소에 올리지 않는다.
- 브라우저에 저장된 API 키는 현재 **localStorage에 평문으로 존재**한다. 백업 파일만 암호화되며, 브라우저 확장·기기 접근자·XSS에 대한 비밀 저장소는 아니다. 공유 기기에서는 사용하지 않는다.

## 폴더 저장의 한계

- 지원되는 데스크톱 Chromium 브라우저의 File System Access API에서는 사용자가 선택한 폴더 아래 `voca앱/voca_user_info.json`을 만들 수 있다.
- 지원하지 않는 브라우저(일부 모바일 Chrome 포함)에서는 일반 파일 다운로드를 사용한다.
- 브라우저가 임의로 파일 시스템에 접근하거나 기기 간 자동 동기화하지 않는다. **학습 후 수동으로 다시 백업**해야 최신 데이터가 남는다.
- 복원은 현재 기기의 동일한 키를 덮어쓰는 방식이다. 가져오기 전 기존 데이터를 먼저 백업한다.
- 단일 JSON 파일은 최신 데이터를 가진 사용자가 이동할 때 사용하는 포터블 백업이며, 두 기기의 동시 수정 내용을 병합하지 않는다.

## 데이터 모델

- `vm-progress-v2`: 능력별 학습 수준·복습 간격.
- `vm-events-v2`: 학습 시도 이벤트.
- `vm-profile-v2`: 학습 목표·TOEIC 점수 등.
- `vm-plan-v2`, `vm-session-v2`: 오늘의 학습 계획·진행 상태.
- `vm-talk-review-v1`, `vm-talk-sessions-v1`: AI 회화 복습과 최근 대화 요약.
- `vm-byok-settings-v1`: 브라우저에 저장된 OpenAI/Anthropic 키와 모델 설정.

## 주의

서버의 기존 `/api/chat`, `/api/talk-feedback`, `/api/mnemonic`은 레거시 호환용으로 남아 있으며, 웹앱의 현재 UI 요청은 브라우저 소유 키를 사용하는 `/api/user-ai`로 연결된다. 실제 배포 브라우저 회귀 테스트는 별도로 필요하다.
