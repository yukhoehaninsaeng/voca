- Source/Mode를 고르지 않는 결정적 오늘 계획, 5분 계획, 복습 우선순위, 하루 학습량 5/10/15/20개 선택

## 기존 설계와 달라진 점

기존 v2 문서는 `itemId` 하나에 Progress 하나를 두었지만 새 요청은 능력별 진도를 요구한다. 따라서 새 기록은 `itemId::skill` 키를 사용하고, 기존 키는 `legacy` 호환 데이터로 보존한다. 기존 화면의 Source/Mode 선택은 삭제하지 않고 자유 연습으로 내렸다. `mastered`를 복습에서 제외하던 동작은 요청서에 따라 due가 되면 다시 선정하도록 바꿨다.

## 다음 Gate 시작점 / 미완료

Gate 2의 서버 AI, 사용자 수정본은 구현하지 않았다. 현재 선택형 브라우저 AI 연결은 개인용 정적 배포를 위한 경로이며 공용 서비스에서는 서버 프록시로 교체해야 한다. 오늘 계획은 현재 존재하는 로컬 플래시카드·입력 문제만 넣으며 미구현 회화 과제를 가장하지 않는다. 날짜가 바뀐 활성 세션을 계속할지 새 계획을 만들지 선택하는 별도 안내와 세션 내 Again 재출제 UI는 후속 보강이 필요하다. Web Speech의 모바일 Chrome/Safari 실제 기기 검증은 수행하지 않았다.

## 영어 발음 재생

단어 카드, 객관식, 받아쓰기 정답과 AI 예문에 발음 듣기 버튼을 제공한다. 발음은 API 키나 추가 과금 없이 브라우저 Web Speech synthesis의 영어 음성을 사용하며, `en-US`, 속도 0.85를 우선 적용한다. 기기에 영어 음성이 없거나 Web Speech를 지원하지 않으면 지원하지 않는다는 안내를 표시한다.


## 첫 학습 및 일일 학습량

사용자는 최초 설정과 오늘 화면에서 하루 학습 표현 수를 5, 10, 15, 20개 중 선택할 수 있다. 변경하면 진행 전 오늘 계획을 같은 날짜 seed로 다시 만든다. 5분 모드는 선택값과 관계없이 최대 5개로 제한한다. 신규 표현은 정답을 가린 채 시험하지 않고 영어·뜻·발음·AI 기억 단서·예문을 먼저 보여 주며, 소리 내기 → 장면 연결 → 눈을 감고 회상하기의 짧은 인코딩 안내를 제공한다.


## 마이페이지 지표와 단계

마이페이지는 StudyEvent와 능력별 Progress에서 공부한 고유 표현, `mastered`인 고유 표현(화면에는 “안정적으로 기억 중”), 학습일, 현재 연속일, 최근 7일 시도·정확도와 누적 시도·정답을 계산한다. 비채점 이벤트는 시도와 정확도에서 제외한다. 사용자가 입력한 TOEIC Speaking 0~200점은 AH/AM/AL/IH/IM/IL/NH/NM·NL 단계로 표시하되, 앱이 추정한 공식 성적이나 보장된 실력 평가로 표현하지 않는다. 사용자는 같은 화면에서 일일 학습량과 점수를 수정할 수 있다.


## 오늘 학습 3단계 반복

오늘 학습은 선택한 표현 전체를 `먼저 익히기 → 뜻 고르기 → 직접 떠올리기`의 세 라운드로 진행한다. 먼저 익히기에서는 영어·뜻·발음·AI 기억 단서·예문을 함께 제시하고 평가 이벤트를 만들지 않는다. 이후 뜻 고르기는 recognition, 직접 입력은 recall로 각각 기록한다. 직접 회상 오답은 정답과 발음을 다시 보여준 뒤 큐 끝에 한 번 더 배치한다. 라운드 큐와 현재 위치는 세션에 저장하여 새로고침 후 이어갈 수 있다.
